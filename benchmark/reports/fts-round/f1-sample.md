## 4. 请复核的四个口径判断

1. **取材是否算独立**：n03 / n04 取自门形状裁定，而本轮判据的门也来自同一份裁定。
   两者是"同一份上游文件的不同用途"（一个当被检索的事实，一个当判定规则），
   我判断这不构成自我指涉，但它比 n01 / n05 那种"上一轮的实验读数"更接近边界。
2. **`fr-a02` 的锚点借用了填充语料**：`配额表` 命中的是中文 filler 的干冰配额表。
   这让该条的 `ftsCount` 由语料保证（预期远大于 1），但也意味着它的词面命中主要来自 filler
   而非 gold——这正是 F0 §1 想要的竞争形态，判断是否可接受。
3. **短查询类用 2 字中文**（`地板`）：它走子串回退分支，与 V1/V2 完全无关，
   作用是回归锚点。判断这是否满足"保护线"的本意，还是应该改成 2 字拉丁（如 `en`）。
4. **`fr-p04` 用 `0.604` 当数字类**：它同时是 n02 的关键事实。判断"用一个只出现在单条记录里的
   数值"是否过于容易，是否需要改成在多条记录里出现的数值（例如 `0.197`）以增加区分难度。

## 5. Codex sample-gate 复核裁定（2026-08-13）

**结论：有条件通过 sample gate，允许准备批量数据；在下列条件完成前不得冻结、跑 ACP 或进入 F2。**

1. **n03 / n04 的来源独立性：通过。** 同一上游裁定文件分别作为被检索事实和验收规则来源，属于不同用途，不算本轮自我指涉。批量记录仍须保留具体 section、代码 symbol/行号，不得把本轮判据文本本身冒充事实来源。
2. **fr-a02：条件通过。** `配额表` 可以保留为中文 filler 造成的词面竞争锚点，但它是合成装置事实，不能冒充项目事实。样本及批量条目须显式记录锚点来源（例如 `anchor_origin: synthetic_fixture` / `filler`），并在报告中将其与 gold 事实分开统计；F2 仍须实测该条 `ftsCount >= 1`。
3. **fr-p01：通过。** 两字中文 `地板` 正是 `<3` 字 LIKE 回退保护线的回归锚点，保留，不改为拉丁短词。
4. **fr-p04：通过。** `0.604` 作为精确数字保护线可保留；它验证具体数值可达性，不承担竞争难度。批量的数字类应另外覆盖版本、阈值或权限等形态，避免八条保护线同质化。
5. **fr-a03：仅样本通过，批量前必须重判。** 在完整 `40` 条新记录 + `26` 条旧记录上逐条确认没有能回答“中性取值后来换成哪个”的变更记录；若发现有，必须改成 `relevance` 并填写对应 `primary_gold`/`acceptable_gold`，不能继续作为负例。

批量冻结前仍需机械复核：40 条新记录均至少一次 `primary_gold`、无 dangling gold、与旧 gold 无重叠、三类负例字段完整，以及 `criteriaRevision: r3` 与当前判据一致。`semantic_query_en` 按既定裁定在 40/120 全部定稿后统一通过生产 ACP 生成，拒绝数必须为 0；余弦四档和 F2 的 `ftsCount`/装置自证属于后续阶段，不能用样本预期替代实测。
